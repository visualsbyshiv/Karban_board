# 🚀 Real-Time Kanban Board (MERN Stack)

A fully functional, real-time collaborative Kanban Board built with the **MERN** stack and **Socket.io**. This project allows users to manage tasks across different stages with instant updates across all connected clients.

## 🌐 Live Demo
- **Frontend:** [https://karban-board.vercel.app](https://karban-board.vercel.app)
- **Backend:** [https://karban-board-backend.onrender.com](https://karban-board-backend.onrender.com)

## ✨ Features
- **Real-time Sync:** Uses Socket.io to sync task movements across all users instantly without page refresh.
- **Full CRUD:** Create, Read, Update, and Delete tasks seamlessly.
- **Persistent Storage:** Integrated with MongoDB Atlas for reliable data storage.
- **Responsive Design:** Works perfectly on desktops, tablets, and mobile devices.
- **Cross-Origin Enabled:** Configured with CORS for secure communication between Vercel and Render.

## 🛠️ Tech Stack
- **Frontend:** React.js, Axios, Socket.io-client, CSS/Tailwind
- **Backend:** Node.js, Express.js, Socket.io
- **Database:** MongoDB Atlas (Mongoose)
- **Deployment:** Vercel (Frontend), Render (Backend)
